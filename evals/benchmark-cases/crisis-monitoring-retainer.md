# Crisis and Monitoring Retainer Benchmark

## Fixture shape

A 24-month scope combines media/social monitoring, daily alerts, intelligence reporting, early warning, reputation advisory, and crisis support. Buyer asks for 24/7 coverage and 30-minute escalation.

## Expected behavior

- define monitored source universe and language coverage
- distinguish machine collection from human validation
- define SLA clock and escalation owner
- build shift/capacity logic for 24/7
- separate monitoring platform/license, analyst service, advisory retainer, and incident surge
- create interface from validated monitoring alert to crisis governance

## Failure oracle

Fail if:
- "real time" remains undefined
- automated sentiment is treated as fact without QA/limitations
- one business-hours analyst funds 24/7
- incident surge is silently unlimited
