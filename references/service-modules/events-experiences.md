# Events and Experiences Module

## Activate for

Conferences, exhibitions, launches, internal gatherings, award ceremonies, brand activations, hospitality, entertainment, visitor journeys, booths, and event production.

## Core design order

1. event objective and audience
2. hard constraints
3. experience principles
4. guest journey
5. program / run of show
6. spatial and technical model
7. suppliers and staffing
8. permits, access, safety, and fallback
9. production schedule
10. closure and reporting

## Discovery questions

- date, city, venue, dimensions, audience count
- attendee profile and dress-code constraints
- public/private/internal status
- existing stage, LED, sound, internet, furniture, catering
- buyer-provided MC or protocol team
- entertainment or performers
- photography/filming permissions
- security and access requirements
- installation and dismantling windows
- supplier and venue restrictions

## Fallback design

Every critical dependency should have an alternative, especially:

- internet
- screen/AV
- performer
- venue zoning
- outdoor weather
- delayed catering
- registration technology

## Pricing implications

Events often mix professional fees, supplier pass-through, rental days, production quantities, staff shifts, logistics, permits, travel, and optional upgrades. Quote validity can depend on supplier availability and date lock.
