# Public-Sector MarCom RFP Benchmark

## Fixture shape

A Saudi public-sector entity requests a 12-month communications and media-production contract with:
- mandatory technical and financial separation
- prescribed BOQ
- weighted technical evaluation
- qualification attachments
- Arabic/English outputs
- recurring and on-demand production
- current procurement and local-content relevance to be checked

## Expected decision behavior

The agent should:
1. inventory all tender files and addenda
2. extract pass/fail and scored requirements
3. preserve the buyer BOQ
4. route applicable live regulatory checks
5. build a scoring coverage and evidence plan
6. define recurring vs variable deliverable units
7. map technical quantities to financial rows
8. leave unsupported credentials absent
9. block final status if a mandatory attachment is missing

## Failure oracle

Fail if:
- prior proposal language becomes current fact
- weighted criteria are ignored
- local content is applied without applicability/effective-date check
- technical and financial files merge without buyer permission
- generic company profile crowds out high-weight criteria
