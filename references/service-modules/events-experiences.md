# Events and Experiences Module

## Activate for

Conferences, exhibitions, launches, internal gatherings, award ceremonies, brand activations, hospitality, entertainment, visitor journeys, booths, workshops, ceremonies, and event production.

## Event classification first

Before design, classify:
- internal corporate / private
- public brand event
- conference/exhibition
- entertainment event/show
- government or protocol-heavy event
- temporary activation/booth

Permit, safety, production, and lead-time assumptions depend on category.

## Core design order

1. objective and audience
2. hard constraints
3. experience principles
4. guest journey
5. program/run of show
6. spatial zoning
7. production and AV
8. hospitality
9. entertainment/activities
10. staffing and protocol
11. permits/access/safety
12. setup/rehearsal/show/dismantle
13. fallback and incident plan
14. reporting and handover

## Discovery

Resolve:
- date, city, venue, dimensions
- attendee count and profile
- dress-code/cultural constraints
- indoor/outdoor
- venue-included AV/furniture/internet
- stage/LED/sound/lighting needs
- MC/protocol ownership
- VIP handling
- catering format
- entertainment/performers
- photography/filming
- registration
- security and access
- installation and dismantling windows
- supplier restrictions
- permit ownership
- travel/accommodation
- giveaway/prize requirements

## Production responsibility matrix

For every physical or supplier item identify:
- design owner
- supplier
- procurement owner
- delivery date
- installation owner
- acceptance check
- backup
- commercial treatment

## Fallback design

Critical dependencies require a fallback:
- internet -> offline registration/quiz/scoring
- AV -> spare signal path or equipment
- performer -> replacement/cancellation plan
- venue zoning -> alternative layout
- outdoor/weather -> indoor/weather decision rule
- catering delay -> service sequencing fallback
- print/signage damage -> spare/rapid print
- logistics delay -> buffer/backup supplier where justified

## Pricing drivers

Price:
- professional fees
- venue/supplier pass-through
- rental days
- setup/rehearsal/show/dismantle
- equipment quantity
- operators
- staff shifts
- logistics
- permits
- travel
- hospitality per attendee
- entertainment/talent
- optional upgrades

Quote validity should reflect supplier availability and date lock when relevant.

## Regulatory triggers

Use Regulatory Scout for exact category:
- GEA entertainment event/show where applicable
- GAMR filming/media where applicable
- venue/municipality/safety
- drone/aviation permissions
- customs for temporary imported equipment

Never quote one permit lead time for all event categories.

## Failure modes

Block or revise when:
- floor plan is "final" without venue dimensions
- AV is priced without distinguishing venue inventory
- performer is promised without availability
- public/private classification is unknown but permit status is asserted
- activity design conflicts with audience/dress code/accessibility
- staffing ignores setup or dismantle shifts
- contingency is an arbitrary percentage with no risk basis
