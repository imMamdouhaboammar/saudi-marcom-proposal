# Artifact Output Contract

## Internal working artifacts

- source inventory
- requirement ledger
- evaluation map
- clarification log
- deliverable map
- internal pricing model
- assumptions register
- risk register
- source ledger
- QC report

These are normally not submitted unless requested.

## Client-facing artifacts

### Technical proposal

Contains solution, scope, methodology, deliverables, schedule, governance, quality, measurement, risk, assumptions, and evidence as required. It normally excludes prices.

### Financial proposal

Contains only the commercial detail appropriate for the buyer. It excludes hidden cost and margin mechanics.

### Compliance appendix

Use when the buyer requests a clause matrix or when a complex government response benefits from explicit traceability.

## Status metadata

Every generated artifact should carry or be accompanied by:

- version
- generated/updated date
- source set used
- status: draft / validation required / final candidate
- unresolved blockers

Do not label an artifact `final` merely because it is polished.
