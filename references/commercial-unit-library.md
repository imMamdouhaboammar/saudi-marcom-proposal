# Commercial Unit Library

This is a unit-design reference, not a price list.

## Purpose

Choose commercial units that correspond to real workload and acceptance.

## Corporate communications and media

Possible units:
- press release
- executive article
- media briefing
- interview coordination
- monthly retainer
- content asset
- production day
- finished video minute
- photography hour/day
- coverage shift

Cost drivers:
- language
- senior review
- urgency
- distribution scope
- production complexity
- approval rounds
- rights

## Marketing and paid media

Separate:
- strategy/management fee
- creative production
- platform operations
- media spend
- third-party tools
- creator/influencer fees

Do not merge media spend into agency revenue in internal profitability views.

## Events

Possible units:
- event
- event day
- attendee
- sqm only when the supplier actually prices by area
- AV package/day
- crew person/day
- stage/show package
- hospitality package
- performer/supplier package

Cost drivers:
- venue
- build complexity
- rehearsals
- access hours
- guest count
- security
- permit lead time
- supplier cancellation terms

## Monitoring and intelligence

Possible units:
- month
- report
- dashboard
- analyst shift
- source/language package
- incident surge
- crisis advisory retainer

24/7 coverage needs a shift and escalation model. A software license alone does not equal 24/7 managed service.

## Crisis and reputation

Separate:
- preparedness/audit
- playbook creation
- training/simulation
- monitoring
- advisory retainer
- incident surge/on-call activation

## Digital products and AI

Possible units:
- discovery sprint
- integration
- workflow
- API connector
- model evaluation cycle
- dashboard
- license/month
- support month
- change request
- training session

Cost drivers:
- data sensitivity
- integrations
- hosting
- model usage
- security testing
- localization
- acceptance testing
- support coverage

## Multilingual work

Price the operational reality:
- source-language creation
- translation
- transcreation
- linguistic QA
- subject-matter review
- approval coordination

A "four-language deliverable" is not automatically four times the base effort, nor should it be assumed free.

## Acceptance-aware pricing

Prefer a unit that the buyer can accept and invoice against.

If the technical acceptance event is "approved monthly sentiment report", a monthly/report unit is usually more traceable than an unexplained lump sum.
