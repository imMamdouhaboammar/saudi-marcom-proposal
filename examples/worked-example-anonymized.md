# Worked Example: Annual Communications and Monitoring Retainer

## Input

A semi-government Saudi entity requests a 12-month communication retainer including strategy, monthly content, production, media monitoring, executive reporting, and crisis support. The RFP contains a scored methodology section, team CV requirements, and a separate mandatory BOQ. It also says "rapid crisis response" without defining hours or SLA.

## Wrong first move

Draft a 40-slide credentials-heavy deck and price one monthly retainer line.

Why it fails:

- no traceability to scoring
- "rapid" remains ambiguous
- monitoring source coverage is undefined
- crisis staffing is not priced
- mandatory BOQ structure is ignored

## Correct route

### 1. Forensics

Create requirement IDs for strategy, content quantity, production, monitoring, reports, crisis support, team, methodology score, BOQ, and submission attachments.

The phrase "rapid crisis response" becomes clarification `C-004` because it can materially change staffing and price.

### 2. Service routing

Activate:

- media-corporate-comms
- monitoring-intelligence
- crisis-reputation

### 3. Technical design

Create workstreams:

- governance and strategic planning
- content and production
- media monitoring and intelligence
- crisis preparedness and response
- reporting and monthly learning

Define monitoring source universe and analytical method. Define crisis severity and a proposed SLA as an assumption only if the buyer has not clarified it.

### 4. Financial design

Preserve the buyer's BOQ. Behind it, model:

- core monthly team
- content quantities
- production allowances or unit rates
- monitoring platform/license if applicable
- analyst/report effort
- crisis preparedness retainer
- surge or after-hours mechanism if allowed

Do not bury unlimited live crisis support inside a normal business-hours retainer.

### 5. Regulatory relevance

If monitoring or campaign operations process personal data, run the PDPL relevance gate. If influencer promotion is later added, run the media-license gate then, not pre-emptively.

### 6. QA

Block submission if:

- mandatory BOQ values do not reconcile to scope
- crisis SLA is still presented as a fact rather than an assumption/clarification
- CV claims are not supported by approved CVs
- technical quantity differs from BOQ quantity

## Result

The final proposal is shorter but more defensible because every scored and commercial commitment is traceable.
